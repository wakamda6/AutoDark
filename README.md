# AutoDark

## 项目说明
AutoDark 是一款基于 MQTT 协议的远程打卡工具，旨在为用户提供便捷的自动化打卡解决方案。
使用本工具时需要注意避免触发系统的检测机制，确保打卡操作的正常进行。

## 功能特点
1. 远程打卡：支持通过 MQTT 协议进行远程操作，打卡效率高，操作简单。
2. 冗余配置：通过定时器，mqtt，qq等操作执行远程打卡，且在屏幕关闭的情况下依然可以打卡。
4. 高兼容性：适配大多数主流 Android 手机（未 Root 且无高风险设置）。

## 使用前提
一部备用手机

## 使用说明
1. 下载本程序到打卡手机，运行，给与必要权限。
2. 设置屏幕常亮。

### 注意事项
使用以下方式打卡，会被dd检测

| 序号  | 原因                                                 |
|:----|:---------------------------------------------------|
| 1   | 手机已经Root，如果已经手机Root，要么换手机要么刷回没Root前的状态，否则想都别想，必被检测 |
| 2   | 手机开启了无障碍服务或者有别的应用用到了无障碍服务，比如：李跳跳之类的辅助软件            |
| 3   | 使用了模拟定位软件试图修改打卡位置（是任何软件，也包括本软件）                    |
| 4   | 使用了向日葵等远程远程控制软件打开                                  |
| 5   | 手机数据线连着电脑且手机开着开发者模式的USB调试功能                        |
| 6   | 试图使用adb命定模拟手指点击打卡                                  |
