## 功能

远程dark

## 使用方法

1. 设置邮箱及通知，悬浮窗等权限开启
2. 打开二维码，使用AutoLite扫描
3. 设置应用省电，自启动，其他权限启动
4. 设置手机屏幕常亮
5. 连接充电器

## 优点

1. 稳定
2. 安全

## 缺点

1. 需要备用手机
2. 需要打卡环境有网
