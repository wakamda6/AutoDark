# 版本更新管理

由于版本更新时需要修改多处地方，需要统一标明

1. build.gradle文件:
   1. versionCode
   2. versionName
   3. 最后修改applicationId

# 证书绑定

由于使用mTLS双向认证，打卡客户端和控制客户端都需要证书，需要绑定

1. 客户端首先安装没有证书的app，初次打开后，需要绑定邮箱
2. 邮箱发送出去，使用ID在后台进行证书生成（使用client_generate.py一键生成）
3. 将生成的证书放到android studio中重新生成app（修改公钥名称为client.en）
4. app发送给安装者，重新安装打开测试


# 权限开通

由于mqtt通信设置有身份验证，需要后台进行开通：

1. 客户端首先安装没有证书的app，初次打开后，需要绑定邮箱
2. 邮箱发送出去，使用ID在后台添加用户名密码。

# 用户使用

1. 运行锁定
2. 省电策略无限制
3. 所有权限打开
4. 屏幕常量，最暗模式
