# 屏幕点击器

### 屏幕点击器PWM控制失败
经验证，esp32不能满足pwm频率为5hz的输出脉冲，因此改为推挽输出控制3.3V（5V更稳定）

### 充电时很不稳定
补充点，亮度调到最低，可以至少12小时待机

### 和屏幕贴合不牢固，时间长了会掉
等待更换模块。找不到合适的模块的情况下，先使用autodingding

 > 经测试，物理屏幕点击头方案，由于硬件限制（电压达不到稳定要求，无法稳定实现功能），暂时放弃硬件方案。
