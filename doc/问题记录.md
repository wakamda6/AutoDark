# mosquitto



### 服务器连接不上

设置用户名密码时要注意

```
//首次添加
mosquitto_passwd -c /etc/mosquitto/pwfile.txt username
//第二次添加不需要使用 -c 选项（它会创建一个新文件并覆盖现有文件）
mosquitto_passwd /etc/mosquitto/pwfile.txt another_username
```

### 关于mqtt服务作为前台服务还是后台服务的问题

经测试，mqtt服务作为前台服务时，没有太大的作用：程序在前台且亮屏时，后台服务会持续运行；如果程序在后台运行，一段时间后，不管有没有前台服务，后台app实际已经停止服务了。因此，前台服务没有太大作用。因此，暂时不设置前台服务。
